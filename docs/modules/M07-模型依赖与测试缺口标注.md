## 1. 真实模型接线在哪（生产路径，逐跳可查）

> 以下行号逐字引自 `overviews/2026-11-21/56a6eec9-M7现状盘点.details.md` §5.1（已与源码核对一致）。

```
worker.main()                              worker.py:90
  → build_deps(dsn, redis_url, owner)      deps.py:247
      → env MODEL_ENDPOINT/MODEL_API_KEY/MODEL_NAME   deps.py:38-40、:265-267
          缺一即 RuntimeError fail-fast               deps.py:268-272
      → gateway = _EnvModelGateway(endpoint, api_key, model)   deps.py:276
          → .complete(messages, tier, stream)         deps.py:194-231
              → model_provider.complete(...)          packages/agent_core/model/provider.py:62
                  → httpx.post(endpoint, ...)         provider.py:80-85   ← 真实 HTTP 调用
                  → with_retry(call)                  provider.py:32-59  429/5xx/网络指数退避（有上限）
                  → normalize_usage(raw)              provider.py:21-29 跨供应商 usage 归一
      → register_capabilities(gateway=gateway, ...)   deps.py:289  ← 视觉理解复用同一 gateway
```

- **配置入口**：`MODEL_ENDPOINT` / `MODEL_API_KEY` / `MODEL_NAME`（`deps.py:38-40`、:265-267），compose 的 `x-app-env` 注入后由 orchestrator 经 `environment: *app-env` 继承（先例见 M04 文档 §1）。
- **换模型不改内核**：不同厂商只改配置（chat-completions 兼容端点），符合 D-4/D-5 决策；但**当前只有一个 `MODEL_NAME`**（`deps.py:276`），按 tier 选多档端点尚未接（见 §2.5）。
- **无 key 时**：orchestrator worker 启动即 `RuntimeError`（`deps.py:268-272`）退出，这是**预期的 fail-fast**，不是 bug——绝不静默换成 fake 冒充生产可用。
- **模型只在网关处出现**：`_EnvModelGateway.complete` 是生产唯一的真实模型出口；记忆学习链路按 ADR-002 **零 LLM 抽取**（`call_count == 0`），不调模型。
- ⚠️ **接线正确 ≠ 质量达标**：上述链路全绿只能证明"给定输入能发出真实 HTTP、usage 能归一"，**不证明**返回内容质量、分类准确率、成本对账无误。

| 项 | 内容 |
|---|---|
| **功能** | M7 §9.0 #1：四级级联 L4，L1–L3 无法裁定时调主 LLM 前沿档，只做**放行方向归类**、禁止作安全裁判（M06 文档 §1.3 同口径）。 |
