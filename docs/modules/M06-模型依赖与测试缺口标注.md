## 1. 因模型缺失无法真测的功能（核心标注）

### 1.1 L2 语义路由 — 真实 embedding 相似度裁定

| 项 | 内容 |
|---|---|
| **功能** | ADR-001 D-8 的 L2：本地 embedding + 意图样本库余弦相似度 + 版本化阈值（0.75）裁定长尾描述 |
| **为何无法真测** | 需真实 embedding 权重 + 意图样本库，`infra/models/intents/<version>/` 不存在（runbook §3 step1）；当前 `DefaultEmbedder` 是纯代码字符 bigram 兜底，不是训练模型 |
| **当前测试覆盖（mock）** | `test_m06_routing_ports.py::test_l2_hit_does_not_call_l3_l4`（FakeEmbedder 相似度 0.86 → L2 裁定）、`test_l2_out_of_scope_is_not_used_as_reject`（L2 违规输出不采纳）、`test_l2_unavailable_degrades_to_l3_with_reason`；A22/A25 用 Fake embedder |
| **mock 能验什么** | ✅ 编排逻辑：阈值比较、命中层裁定、降级 L3、拒绝类不采纳、0 下游调用 |
| **mock 不能验什么** | ❌ 真实相似度分布是否合理、阈值 0.75 是否校准（影子期升级率 <30%）、长尾描述召回率、意图样本库覆盖度 |
| **真测所需** | ① 权重文件放 `infra/models/intents/<version>/`（≥30 条/意图）；② 容器挂载 `./infra/models:/app/infra/models:ro`；③ 实现 `ports.Embedder` 并注入 `classify_intent(embedder=...)`；④ 影子期校准阈值 |
| **接线点** | `services/guardrails/ports.py::Embedder` → `classify_intent(embedder=...)` |

### 1.2 L3 小模型分类器 — 低档端点意图分类

| 项 | 内容 |
|---|---|
| **功能** | D-8 的 L3：L2 置信度不足时调低档小模型（token ≤512）输出意图 + 结构化置信 |
| **为何无法真测** | 需 M20/M07 的 `ModelGateway` 低档端点，当前未配置；`RuleBasedClassifier` 默认返回"不可解析"只触发升级 |
| **当前测试覆盖（mock）** | `test_l3_hit_does_not_call_l4`（FakeClassifier 可解析 → L3 裁定）、`test_l3_unavailable_degrades_to_l4_with_reason`、`test_l3_unparseable_degrades_to_l4_with_reason`；A23 用 Fake classifier |
| **mock 能验什么** | ✅ token 上限被强制、可解析性校验、不可用/不可解析→升 L4、归因字符串 |
| **mock 不能验什么** | ❌ 真实模型分类准确率、结构化置信区间是否合理、低档端点延迟/成本 |
| **真测所需** | ① M20/M07 提供低档端点；② 实现 `ports.IntentClassifier` 并注入 `classify_intent(classifier=...)`；③ 用标注集测准确率与误放行率 |
| **接线点** | `services/guardrails/ports.py::IntentClassifier` → `classify_intent(classifier=...)` |

### 1.3 L4 主 LLM 兜底 — 前沿端点裁定

| 项 | 内容 |
|---|---|
| **功能** | D-8 的 L4：L1–L3 均无法裁定时调主 LLM（计入成本账），只做放行方向归类、禁止作安全裁判 |
| **为何无法真测** | 需 M07 `ModelGateway` 前沿档位端点，当前未配置；`StructuredFallback` 默认不调模型、结构化归类为 WIDGET_GENERATION |
| **当前测试覆盖（mock）** | `test_l4_gateway_injected_and_called`（FakeGateway 被调用）、`test_l4_gateway_reject_is_not_used_as_security_judge`（L4 不越权拒绝）、`test_l4_unavailable_falls_back_to_structured` |
| **mock 能验什么** | ✅ L4 注入即调用、白名单方向归类、违规输出不采纳、异常回落结构化兜底 |
| **mock 不能验什么** | ❌ 真实主 LLM 兜底裁定的准确率、成本账归集、延迟 |
| **真测所需** | ① M07 提供前沿端点；② 实现 `ports.IntentGateway` 并注入 `classify_intent(gateway=...)`；③ 跑标注集验收兜底质量 |
| **接线点** | `services/guardrails/ports.py::IntentGateway` → `classify_intent(gateway=...)` |

### 1.4 标注集校准（A14/A25 真值来源）

| 项 | 内容 |
|---|---|
| **功能** | A14 误拦截率、A25 级联命中率/升级率复算需要人工标注集做真值 |
| **为何无法真测** | 无真实标注集文件；当前 A14 用合成数据（10/50=0.2）、A25 用合成日志复算 |
| **mock 能验什么** | ✅ 统计公式与口径正确 |
| **mock 不能验什么** | ❌ 真实误拦截率数值、真实升级率是否 <30%、阈值/规则是否需校准 |
| **真测所需** | M10/M19 提供标注集（含"应放行但被拦"标签），接入 `false_positive_rate` 与 `IntentRouteLog.stats()` |

### 2.1 【已补全】M06 本模块功能（本轮实现 + 测试）

| # | 功能点 | 设计依据 | 补全过程 |
|---|---|---|---|
| 1 | REST `/api/guardrails/hits` / `/api/skills` 端点 | §4.1 端点表 | ✅ `services/guardrails/api/main.py` 从 health stub 补 `create_app()`：hits 查询（hit_type/rule_id 过滤 + cursor 分页 + FPR）、skills 只读 manifest；4 个 API 测试通过 |
| 4 | 事件 `error` 通道、`skill.need_skill`、`guard.code` 细分 | §4.2 事件表 | ✅ `_terminal()` 对越界/预算终态推 `error { code, evidenceRef }`；skill 事件带 `need_skill`；guard.code 按命中类型细分（非恒 GUARD_INPUT_HIT） |
| 5 | 描述充分性"控件类型/关键特征"槽位检查 | R1 / §3.2 step2 | ✅ `_has_required_slots()` 基于 WIDGET_HINTS + FEATURE_HINTS 规则词表（零模型）；缺槽位 → INPUT_INVALID + 具体建议 |
| 7 | `audit.py` 只追加审计 + `input_snapshot` / `evidenceRef` | §2.4 / §6.5 | ✅ 新建 `services/guardrails/audit.py`：只追加 AuditEvent + 输入快照（仅描述/附件引用/grid，**不含原文**）+ sha256 + evidenceRef；validate_chain 每请求写 SNAPSHOT 审计并在 ValidationResult 带 evidenceRef |
| 8 | `suggest_grid` 全特征冲突过滤 | §3.4 G | ✅ `_detect_conflict_features()` 从描述抽所有冲突矩阵特征，偏好项与典型密度项都按全特征过滤（非仅 calendar+月视图） |

**安全顺序修正**（本轮连带发现）：注入/PII 护栏提到语义层之前——注入描述多不含控件槽位，
先过语义层会被"描述不足"拦下导致 reason_code 失真（A1 期望 GUARD_INPUT_HIT）。
安全红线优先，与 step0 越界前置短路同级，零模型调用。

新增测试：`tests/unit/test_m06_completeness.py`（12 用例）、`tests/unit/test_m06_api.py`（4 用例）。
