## 1. 4 道理解关（分级定义）

| 关 | 名称 | 深度/标准级（后端） | 快速级（前端，只看交互） |
|---|---|---|---|
| **G1** | 三问关 | 脱稿讲清：① 14 步第几步、上下游；② 输入/输出/挂哪个机制（decide 分支/hook/Port）；③ 挂了产生什么 ReasonCode、前端状态 | 讲清：调哪些 REST / 消费哪些 SSE 事件 / 事件如何驱动页面 |
| **G2** | 代码定位关 | 不看文档指出 3 个关键位置：入口/核心逻辑/状态机或判定树 | 指出交互层文件：哪个调 API、哪个订阅 SSE |
| **G3** | 追问关 | 答对 3 个「为什么」（深度 3–5 个） | 答对 1 个交互问题 |
| **G4** | 笔记关 | `docs/全链路理解笔记.md` 写满 7 项 | 写交互 3 项（REST / SSE / 状态对齐） |

**四关全过 = 解锁下一个**。前端「弄明白」= 说清调什么接口、消费什么事件、状态怎么对齐；页面内部不深究。
