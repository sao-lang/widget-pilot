## 0. 整体认知

M9 承载 X9 运行时隔离部分（与 M08 沙箱测试、M16 卡片渲染共用 WidgetRuntime 契约），主责 14 步链路的 ⑪⑫ 步。
它是**产物收纳方 + 协议下发方**：M08 产出校验结论与编译产物引用，M07 产出 spec 与源码引用，
M09 把二者收敛成可管理、可回滚、可隔离渲染的 `WidgetBundle`。D-5 零 Agent 框架成立（无 LLM/Agent 框架依赖）。

**职责边界（禁止越界，设计 §1.3）**：产代码/编译/沙箱测试归 M07/M08；卡片网格 iframe 装配归 M16；
artifact 消费归 M14；公共语料入库/撤回归 M10；会话状态机/seq 归 M04/M03；成本/治理归 M11。

## 2. 一条主线：从 M08 结论到 artifact 事件

```
M08 ValidateResult（output_guard + contract_check + sandbox_test + evidence_refs）
  → BundleService.assemble()
      → adapter.adapt_validation_to_bundle()  # 折叠 static_check/sandbox_test，三门禁全过才继续
      → _fill_manifest() + hash.compute_bundle_hash()  # hash 链：spec_hash/compiled.hash/整包 hash
      → versions.append_version()  # 首版节点
      → PgBundleStore.insert()  # 写 widget_bundle + bundle_version（迁移 0019）
      → AuditLedgerPort.append(bundle_assemble)  # 只追加审计
      → M04ArtifactSink.emit("artifact", {bundle_id, preview_ref, grid, state, hash}, session_id)
          → TypedEventEmitter → RedisSeqAllocator.next → RedisEventBus.emit  # M04 SSE 扇出
```

## 3. 渲染协议（运行时隔离，X9）

- `runtime.build_runtime()` 按 grid 算 `card.px`（80px cell 六种真实比例），`iframe.sandbox = ("allow-scripts",)`，
  `csp = STRICT_CSP`（禁外联/禁 eval/禁网络），`capability_bridge = manifest.capabilities ∩ 全局白名单`。
- `bridge.py` 7 条消息白名单 + `is_capability_allowed`；未声明能力调用拒绝并上报 `widget:error`（A9）。
- 时间统一 `host:tick`、存储 `storage_namespace = user_id:bundle_id`（service.preview 构造）。
- 前端 bridge 实现 `packages/widget_bridge/ts/index.ts` 与 Python `bridge.py` 常量口径一致（契约 `enums.source.json` 权威）。

---

## 4. 状态机与幂等

- `state.transition()` 纯函数：`_ALLOWED` 映射定义每态允许动作（DELETED 无出边）；install 幂等收敛 INSTALLED；
  delete 先校验 confirm_token 再不可逆迁移。持久化与审计由 BundleService 在同一次调用内完成（内核无 IO）。
- 幂等键：install = 状态已 INSTALLED 时 `update_state` 返回 False → 不重复写审计；delete/rollback 每次写审计（业务操作）。
- 审计动作常量在 `service.py`：`bundle_assemble/install/delete/rollback`（`AuditActions` 后续可同步扩充）。

---

## 5. 版本链与回滚

- `versions.append_version()` 追加节点（parent 指针单调）；`rollback()` 沿用目标版 `compiled_ref/hash`，
  **不重新编译、不调模型、不改 BundleState**（A15 / Q12）。
- `PgBundleStore.replace_versions()` 覆盖 JSONB 列 + 补插新节点行（幂等去重）。
