# Change: f76a7264-local-model-interpreter-v3 / 2026-11-25 / confirmed

## Why
用户 14:19 担忧零 LLM 链路「不太行」，实测证实担忧部分成立：24 条复杂描述切片法仅 21%，全局抽取法虽 75% 但有「桌面+卡片数成 2」的假阳性；现有默认 bigram embedder 对真实描述相似度 0.40-0.59 全不达标。用户 14:24 明确要求「加进本地小模型兜底，重新设计解释器，尽量覆盖混乱描述」。这是从 v2「严格零 LLM」到「零云端 LLM + 本地模型兜底」的方向变更。

## Delta
- 新增 `services/guardrails/interpreter/`：`Interpreter` 协议 + `RuleInterpreter`（v2 编译器 + 共现消歧）、`LocalModelInterpreter`（onnxruntime 真权重）、云端兜底适配器（复用 `run()`→`CALL_MODEL`）。
- 新增共现消歧：宿主词位置 + 连接词边界 + grid 位置/数量联合裁定 widget 实例数（修「桌面+卡片=2」假阳性）；分散槽位按最近宿主聚合；后置 grid 按实例顺序分配。
- 新增本地模型端口与权重加载（env 路径 + fail-fast），输出过 schema/domain/出护栏校验；缺权重告警降级，禁止 bigram 冒充。
- 新增按层可观测（layer_used/confidence/降级原因/模型版本）。
- 新增 `docs/modules/M06-模型依赖与测试缺口标注.md`（六栏缺口登记）。
- ADR-016 为设计权威；ADR-015 理解层被覆盖，其余成果保留。本主题 v1/v2 契约历史保留。无删除公共符号。

## Invariants
- 公共 JSON Schema 不改（`widget_spec`/`widget_bundle`/`events`）；`run()`/`decide()`/`Deps.model` 不改。
- 本地模型不得输出拒绝类（OUT_OF_SCOPE/注入/PII）；安全护栏仍在解释器之前。
- 无权重 fail-fast，不静默用 bigram 冒充；模型质量与接线正确分开记账。
- ADR-004 三条硬样本与去类型化内核不变；I14 拒绝类零模型。
- 降级链路单向（规则→本地→云端），禁二次降级/无限重试；产物过 M08 三门禁。
