## 决策结论（保留防重复评估）

用户问"前端能不能用 Next.js"。评估后**不建议**，核心冲突三条：
1. Next 的 SSR/RSC 模型 vs 现有客户端 event-sourced + SSE 长连接回放架构——冲突。
2. Next API Routes 服务端判定 vs 项目 BFF 硬约束"不做鉴权判定"——越界。
3. Node 运行时部署 vs web 静态 CDN 部署——不匹配；且迁移成本（测试栈/回放夹具/契约生成）高，SEO/首屏收益在本产品近乎为零。

**若诉求细分**（未落实，仅备查）：SEO/营销站→另起独立 Next 应用，不混改 apps/web；路由/布局→TanStack Router 或 React Router 即可；BFF→保留现有独立 apps/bff。
